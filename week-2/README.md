# Тиждень 2 · Стратегія проспектингу

Уроки: 03 Ринок, ICP, скоринг і конкуренти · 04 Персони і шлях клієнта.

## Встановити весь тиждень

```bash
npx skills add victor-shulga/ai-native-outreach-skills/week-2
```

Без терміналу: завантажте теку `week-2/skills/<скіл>` як ZIP і в Claude Desktop: Settings → Capabilities → Skills → Upload a skill.
