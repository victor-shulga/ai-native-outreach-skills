# Тиждень 2 · Стратегія проспектингу

Уроки: 03 Ринок і ICP · 04 Персони і шлях клієнта.

## Встановити весь тиждень

```bash
npx skills add victor-shulga/ai-native-outreach-skills/week-2
```

Без терміналу: завантажте теку `week-2/skills/<скіл>` як ZIP і в Claude Desktop: Settings → Capabilities → Skills → Upload a skill.

## Скіли тижня

| Скіл | Навіщо на цьому тижні | Окремо, з основного паку |
|---|---|---|
| `gtm-market-sizing` | TAM: скільки компаній на вашому ринку. | `npx skills add victor-shulga/gtm-strategy-skills/skills/gtm-market-sizing` |
| `icp-builder` | Документ ICP: межі ринку, анти-ICP чотирма кільцями, «чому покупець, а не конкурент», сигнали ранжують акаунти. | `npx skills add victor-shulga/outbound-engine-skills/skills/icp-builder` |
| `icp-validation` | Перевірка ICP на ваших реальних кейсах і угодах. | `npx skills add victor-shulga/outbound-engine-skills/skills/icp-validation` |
| `gtm-market-icp-persona` | Ринок → 3 тіри акаунтів → ОПР і чемпіон з JTBD і процесом покупки. | `npx skills add victor-shulga/gtm-strategy-skills/skills/gtm-market-icp-persona` |
| `persona-builder` | Картка персони під конкретну посаду: що болить, як писати цій ролі. | `npx skills add victor-shulga/outbound-engine-skills/skills/persona-builder` |
| `gtm-buyer-journey` | Карта шляху клієнта і точка, де входить аутріч. | `npx skills add victor-shulga/gtm-strategy-skills/skills/gtm-buyer-journey` |

Копії взято з основних паків. Оновлення приходять туди першими; ця тека синхронізується скриптом `sync.py`.
