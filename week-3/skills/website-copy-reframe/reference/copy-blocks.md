# Copy-block templates and worked example

Templates for turning the canvas into homepage copy. Each block cites the canvas cell it draws
from. Keep copy concrete, keep the situation tool-agnostic, keep positioning vertical. Edit for AI
tells before shipping (stock phrases, negative parallelism, bureaucratic tone).

## Canvas table (fill this first, one primary use case)

| Left half (current path) | | Right half (your service) | |
|---|---|---|---|
| **Audience** | company type × person × situation | **Capabilities** | what the client does with the service |
| **Champion** | who feels the pain and pushes the deal | **Features** | the mechanics that make the capability real |
| **Situation / activities** | functional, tool-agnostic | **Benefits** | the result of using the capability |
| **Current way** | how they handle it today | | |
| **Limitations** | neutral facts about the current way | | |
| **Problems** | what the limitations cost the champion | | |

Links: capabilities **improve** limitations; benefits **remove** problems.

---

## Hero (top-row message, key capabilities, category, trust)

```
[Service category the market already searches for]
H1: <capability the champion gets> for <specific audience>
Sub: <how it works in one line: the feature that makes the capability real>
     <the benefit that removes their top problem>
CTA: <next step: book a call / get an estimate / request a sample>
Trust: <logos · number of projects · geography · certification · years>
```
*Rationale:* H1 = top row + key capability. Sub = feature + benefit. Trust = proof from the proof
bank.

**Worked example (a fractional GTM consultant's own homepage)**
- Category: *Fractional GTM for B2B service companies*
- H1: *Generate pipeline and close more deals*
- Sub: *With SOPs, frameworks, templates and an operator who has hit these targets before, so new
  revenue comes from leads that fit your ICP.*

## Problem section (current way → limitations → problems)

```
Header: <name the situation the champion is working on>
Lead: <empathy line: "if you are trying to <situation>, you have probably tried <current way>">
3 bullets, each = one limitation and the problem it causes:
  • <limitation of the current way>, which means <problem for the champion>
Close: <one line that turns away a bad fit and confirms a good fit>
```
*Rationale:* taken straight from the current way, limitations and problems cells. Purpose: the
right visitor feels understood, the wrong one self-selects out.

---

## Solution (three arguments → next step)

```
Header: <the progress the champion wants to make>
3 argument cards, each = capability + feature + benefit:
  1. <capability>: <feature that enables it> → <benefit that removes a problem>
  2. ...
  3. ...
CTA: <same next step as the hero: form or calendar>
```
*Rationale:* drawn from the capabilities, features and benefits cells. These are the three
reasons to act now.

---

## Optional lower-half sections (pick per company; each routes to another page)

- **Services**: a grid of services, each linking to its service page.
- **Industries**: verticals served, linking to industry pages.
- **Testimonials**: quotes tied to the champion's problem.
- **Why work with us**: differentiators (team, process, awards, guarantees).
- **Persona segmentation**: how persona A uses the service, how persona B uses it.
- **Company segmentation**: how industry A uses it, how industry B uses it.
- **ROI**: numeric outcomes with their source.
- **Calendar / form**: the final low-friction CTA.

## Reframe heuristics (turning scraped copy into the canvas)

- The scraped headline is usually a founder's list of capabilities. Treat it as raw material and
  work out the champion's situation underneath it.
- "We offer X, Y, Z": ask which activity the champion is doing that needs X. That activity goes
  into the situation row.
- Adjective trust claims ("innovative", "reliable", "cutting-edge"): cut them and put a feature
  (a concrete mechanism) or a numeric benefit in their place.
- Copy that speaks to the executive buyer: rewrite one level down, to the champion.
- "We help all kinds of businesses": pick one vertical (framework Step 2).

## Buzzword swap list (English copy)

Filler phrases signal "average" and cost trust. When one shows up in scraped copy or in a draft,
replace it with the proof it is standing in for. Deleting it is not enough; the point is to force
a specific claim.

| Phrase | Replace with |
| :-- | :-- |
| results-driven | the result, as a number |
| proven track record | the track record itself (projects, years, clients) |
| passionate about | something you built or shipped |
| seasoned / experienced | years plus specialty |
| strategic | a strategy you executed and what it changed |
| detail-oriented | the QA step or process you run |
| innovative | the thing you actually invented |
| leverage | "use" |
| thought leader, synergy, dynamic, guru, ninja, rockstar | delete |

Test for any line: if it survives a sceptical buyer asking "prove it", keep it.
