# Тиждень 3 · Підготовка до запуску

Уроки: 05 Позиціонування й офери · 06 Докази і контент.

## Встановити весь тиждень

```bash
npx skills add victor-shulga/ai-native-outreach-skills/week-3
```

Без терміналу: завантажте теку `week-3/skills/<скіл>` як ZIP і в Claude Desktop: Settings → Capabilities → Skills → Upload a skill.

## Скіли тижня

| Скіл | Навіщо на цьому тижні | Окремо, з основного паку |
|---|---|---|
| `gtm-positioning` | Шість слотів позиціонування і таблиця «було і стало». | `npx skills add victor-shulga/gtm-strategy-skills/skills/gtm-positioning` |
| `gtm-value-prop` | Ціннісна пропозиція під персону. | `npx skills add victor-shulga/gtm-strategy-skills/skills/gtm-value-prop` |
| `gtm-offers` | Офери під сегменти. | `npx skills add victor-shulga/gtm-strategy-skills/skills/gtm-offers` |
| `offer-ladder` | Драбина з чотирьох оферів і перша сходинка для холодного листа. | `npx skills add victor-shulga/sales-engine-skills/skills/offer-ladder` |
| `case-study-writer` | Кейс під офер: проблема з цифрою, хід проєкту, результат. | `npx skills add victor-shulga/account-management-skills/skills/case-study-writer` |
| `website-copy-reframe` | Перепис головної і сервісної сторінки під ICP. | `npx skills add victor-shulga/marketing-engine-skills/skills/website-copy-reframe` |
| `page-builder` | Сторінка під гіпотезу або лід-магніт. | `npx skills add victor-shulga/page-builder/skills/page-builder` |

Копії взято з основних паків. Оновлення приходять туди першими; ця тека синхронізується скриптом `sync.py`.
