# Тиждень 4 · Гіпотези й радари

Уроки: 07 Матриця гіпотез · 08 Дата-ресерч і сигнали.

## Встановити весь тиждень

```bash
npx skills add victor-shulga/ai-native-outreach-skills/week-4
```

Без терміналу: завантажте теку `week-4/skills/<скіл>` як ZIP і в Claude Desktop: Settings → Capabilities → Skills → Upload a skill.
