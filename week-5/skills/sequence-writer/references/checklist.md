# Pre-send checklist

Run every line. A sequence failing any hard rule is rewritten, not shipped with
a caveat.

## Gate

- [ ] Over 10% of the accounts in the list carry a signal or a data-point
- [ ] Sending domains separate from the main domain, SPF + DKIM + DMARC in place
- [ ] Warmup finished, bounce under 2%, open tracking off
- [ ] Monthly capacity computed (`mailboxes x 25 x 20`) and the segment sized against it
- [ ] The asset promised by the CTA already exists as a file
- [ ] A named person reads the inbox daily and replies the same working day

## Anchor

- [ ] The type is declared (A / B / C) and one type only in this campaign
- [ ] Type A: both check questions answered, and the signal is inside its window
- [ ] Type B: the data-point carries a comparison, not just a number
- [ ] Type C: the first line could NOT be pasted unchanged into an email to their competitor
- [ ] One anchor carries every email in this persona's sequence

## Every email

- [ ] Subject: lowercase, three words or fewer, describes their problem
- [ ] Opens with the observation, not with an introduction of yourself
- [ ] No "I hope this finds you well" or any variant of it
- [ ] The problem is stated, as a consequence they recognise
- [ ] Proof is one story, one number, with the client as the subject
- [ ] Exactly one question, and it is the last line
- [ ] No call, meeting, calendar link, or "worth a chat"
- [ ] No statement disguised as a question ("curious whether…", "let me know if…")
- [ ] No start date offered
- [ ] No links, images or attachments in email 1
- [ ] Within the word cap: 75 / 50 / 45 / 35 / 25
- [ ] No spintax and no variable dropped into an empty sentence

## Cadence

- [ ] Days 0 / 3 / 8 / 14 / 21, or the compressed schedule matching the signal window
- [ ] Emails 2–4 are replies in the same thread; email 5 has a new subject
- [ ] The sequence stops when the signal window closes
- [ ] The second contact at the company is a parallel sequence, 5-day offset, different mailbox, own anchor
- [ ] No persona swap inside a sequence

## LinkedIn

- [ ] Invite note written, 120–180 characters, sells nothing
- [ ] First message after accept 150–300 characters
- [ ] Three touches, and the follow-up carries something new rather than a nudge
- [ ] 10–19 invites per day per profile, ~100 per week
- [ ] No auto-likes or auto-views as warmup
- [ ] A referral is asked for directly, with the name, and without a hedge

## Measurement

- [ ] The denominator is written down: human replies ÷ emails sent
- [ ] The expected range matches the anchor type, not one generic benchmark
- [ ] The readable-from sample size is stated
- [ ] The stop rule is stated
