# Тиждень 5 · Запуск кампанії

Уроки: 09 Сіквенс · 10 Запуск кампанії.

## Встановити весь тиждень

```bash
npx skills add victor-shulga/ai-native-outreach-skills/week-5
```

Без терміналу: завантажте теку `week-5/skills/<скіл>` як ZIP і в Claude Desktop: Settings → Capabilities → Skills → Upload a skill.

## Скіли тижня

| Скіл | Навіщо на цьому тижні | Окремо, з основного паку |
|---|---|---|
| `signal-outbound` | Оркестратор: від сигналу до готового сіквенсу. | `npx skills add victor-shulga/outbound-engine-skills/skills/signal-outbound` |
| `sequence-writer` | Сіквенс на 21 день у двох каналах під одну гіпотезу. | `npx skills add victor-shulga/outbound-engine-skills/skills/sequence-writer` |
| `multi-channel-orchestrator` | Пошта і LinkedIn як один дотик. | `npx skills add victor-shulga/outbound-engine-skills/skills/multi-channel-orchestrator` |
| `linkedin-sequence` | Повідомлення в LinkedIn на 150–300 символів. | `npx skills add victor-shulga/outbound-engine-skills/skills/linkedin-sequence` |
| `followup-sequence` | Фолоуапи без повторів. | `npx skills add victor-shulga/outbound-engine-skills/skills/followup-sequence` |
| `subject-line-generator` | Теми листів. | `npx skills add victor-shulga/outbound-engine-skills/skills/subject-line-generator` |
| `cta-interest-based` | Заклик до дії питанням, без прохання про дзвінок. | `npx skills add victor-shulga/outbound-engine-skills/skills/cta-interest-based` |
