# Тиждень 6 · Відповіді й аналітика

Уроки: 11 Робота з відповідями · 12 Аналітика і дашборди.

## Встановити весь тиждень

```bash
npx skills add victor-shulga/ai-native-outreach-skills/week-6
```

Без терміналу: завантажте теку `week-6/skills/<скіл>` як ZIP і в Claude Desktop: Settings → Capabilities → Skills → Upload a skill.

| Скіл | Навіщо на цьому тижні | Окремо, з основного паку |
|---|---|---|

| `reply-audit` | Розбір усіх відповідей кампанії за класифікацією. | `npx skills add victor-shulga/outbound-engine-skills/skills/reply-audit` |
